CRYSTAL REMOTE CATALOG v1.11.0

Repo:
https://github.com/y2kbeatzz-dot/CRYSTAL-REMOTE-CATALOG-v1.11.0

GitHub Pages:
https://y2kbeatzz-dot.github.io/CRYSTAL-REMOTE-CATALOG-v1.11.0/

1. GitHub Pages publishes from main /docs.
2. GitHub Actions runs .github/workflows/update-avatar-catalog.yml automatically.
3. Use these URLs in Unity:

Catalog:
https://y2kbeatzz-dot.github.io/CRYSTAL-REMOTE-CATALOG-v1.11.0/catalog.txt

Creator/Fallback Shards:
https://y2kbeatzz-dot.github.io/CRYSTAL-REMOTE-CATALOG-v1.11.0/catalog-shards/

Avatar Name Search:
https://y2kbeatzz-dot.github.io/CRYSTAL-REMOTE-CATALOG-v1.11.0/search2/

4. In Unity:
   Crystal GUIs -> Configure Remote Catalog

5. Apply the URLs to the open avatar browsers.
6. Upload your VRChat world.

The browser keeps bundled data as a fallback if the remote host is unavailable.
